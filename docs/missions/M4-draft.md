# M4 시험 렌더 — 요구사항

> M1 기획 → M2 스토리보드 → M3 음악 → **M4 시험 렌더** → M5 최종

| 항목 | 내용 |
|---|---|
| 목표 | 구성을 만들고 30fps 초안으로 리듬을 실제로 잰다 |
| 무게 | 무거움 |
| 승인 | 사람 (G4, 보고) |
| 입력 | storyboard.json · bgm.wav · 템플릿 |
| 결과물 | `projects/<이름>/draft.mp4` |
| 스킬 | opus-5-5-video-templates (0.8.96 고정) · hyperframes* · hyperframes-registry |
| 시작 조건 | 빈 메모리 2.5GB 이상 · 다른 무거운 작업 없이 혼자 |

## 해야 할 일 (기능)

| ID | 요구사항 | 확인 |
|---|---|---|
| F4.1 | 템플릿 복사 또는 새 프로젝트 (CLI 버전을 섞지 않는다) | ☐ |
| F4.2 | 스토리보드 시간·전환·음악을 넣는다 | ☐ |
| F4.3 | 30fps, 워커 1개로 렌더한다 | ☐ |

## 통과 기준 (자동 측정)

| ID | 항목 | 기준 |
|---|---|---|
| C4.1 | fps | 30 |
| C4.2 | 길이 | ±0.15초 |
| C4.3 | 초당 컷 | 0.6~0.8 (fast) |
| C4.4 | 잰 몰아치기 위치 | 55~75% (fast) |
| C4.5 | 소리 | 있음 |
| C4.6 | 계획대로 잘림 | 계획 컷의 80% 이상이 ±0.1초 안 |
| C4.7 | 박자에 컷 | 잰 컷의 80% 이상이 8분음표 ±0.05초 안 |

## 판정 방법

1. 감독이 기능 F4.x를 모두 한다.
2. `mission_check.py draft`가 기준을 잰다 → `video-mission-draft-check.json`.
3. 기준을 하나라도 못 넘으면 승인 문이 안 열린다. 고치고 다시 잰다.
4. 사람만 "Override"로 넘길 수 있고, 그 결정은 기록된다.

요약 파일: `video-mission-draft.md` (Mission · Result · Checks · Verdict · Next)
